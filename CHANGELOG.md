# Changelog

Notable SavedAgain changes are recorded here. The project uses semantic version tags while it remains a personal-use source-available beta.

## Unreleased

- Public-release hardening, reproducible dependency pins, offline model manifest and environment doctor.
- Cloudflare template generation, GitHub security automation and curated tagged-release archives.

## 1.1.0 - 2026-11-12

- Added local user-supplied reel ingestion, resumable multimodal analysis and transparent classification fusion.
- Added VoiceStudio-only transcription contract with local-only transcript storage and explicit waiting states.
- Added optional Cloudflare Worker/D1/private-R2 dashboard mirror and conflict-aware local synchronization.
- Added privacy projection tests, D1 migrations and manual-category protection.

## 1.0.0

- Initial SavedAgain personal skill, private dashboard, browser capture workflow, SQLite library and synthetic demo.
