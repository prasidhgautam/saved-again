# SavedAgain contributor instructions

The reusable skill is self-contained under skills/saved-again. Keep dashboard source in its assets/dashboard directory. No dependency on a separately installed skill or paid API is required.

Use synthetic test/demo records only. Never copy a real library, access key, original Instagram preview, browser checkpoint or personal screenshot into this repository. Keep runtime data outside installed skill and application source. Browser imports remain read-only on Instagram and require supported logged-in browser tools.

Preserve the Matchbox design and the starter Sites packaging files. Run backend tests, manager tests, release validation, the production build and Sites tests after relevant changes. Keep README compatibility claims limited to tested facts. Do not change the personal-use license or publish without a user request.

Dynamic category labels must remain inside the matchbox frame. Keep custom-label styles separate from fallback-cover styles. Visual checks must include the complete category grid, custom covers, long labels and phone details/settings, not only the initial viewport.
